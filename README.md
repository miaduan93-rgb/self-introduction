## 🚀 本地与远程同步（Git 五步走）

```bash
git init                # 1. 初始化本地仓库
git add .               # 2. 暂存所有改动
git commit -m "init"    # 3. 提交到本地仓库
git remote add origin git@github.com:miaduan93-rgb/self-introduction.git  # 4. 关联远程仓库
git push -u origin main # 5. 推送到 GitHub
```
